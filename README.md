# PEDIDOS_many_to_one

Aplicación desarrollada con Spring Boot para gestionar pedidos y clientes mediante una relación *Many-to-One* utilizando JPA y Hibernate.  
El proyecto sirve como ejemplo práctico de modelado de entidades y persistencia de datos en bases de datos relacionales.

## Tecnologías utilizadas

- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Maven

## Funcionalidades

- Crear y gestionar clientes
- Registrar pedidos asociados a un cliente
- Implementación de relaciones Many-to-One
- Persistencia de datos con JPA/Hibernate
- Operaciones CRUD básicas

## Objetivo del proyecto

Practicar el uso de relaciones *Many-to-One* en aplicaciones Java con Spring Boot, aplicando conceptos de persistencia, asociaciones entre entidades y arquitectura MVC.
